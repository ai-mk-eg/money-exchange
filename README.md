# صرافة — دولار ⇄ مصري

برنامج سهل لمحل الصرافة: تسجيل الدولار اللي استلمته أو سلمته بعدد الورق، المصري المدفوع أو المستلم، المتبقي على/للعميل، ودفتر العملاء، والتقارير، وقفل الوردية كل يوم.

**افتحه من هنا:** https://ai-mk-eg.github.io/money-exchange/

- بيتسطب على الموبايل كأنه تطبيق (من قايمة المتصفح: "إضافة للشاشة الرئيسية")
- بيشتغل من غير نت بعد أول مرة
- البيانات محفوظة على الجهاز نفسه بس — خد نسخة احتياطية من الإعدادات كل فترة
